12. Компактная грамматика

Все основные формулы на одном листе.

Времена

usually/every → Present Simple
now/today → Present Continuous
yesterday/last/ago → Past Simple
ever/yet/result → Present Perfect

Помощники

be + adj/place/-ing
do/does/did + V1
have/has + V3
modal + V1

Формы

did + go, не went
have + gone
is + working
used to + work

Артикли

a/an — один впервые
the — конкретный
∅ — вообще
some/any — количество

Предлоги времени

at — точка
on — день/дата
in — период
for — длительность

Наречия

slow → slowly
happy → happily
good → well
fast/hard → fast/hard

Вопросы

Do/Does/Did + S + V1?
Be + S + ...?
Have + S + V3?
Who/What/Where/When/Why/How

Сравнение

big → bigger
famous → more famous
the biggest / the most famous
as ... as

Порядок слов

Subject + Verb + Object
Subject + be + adjective/place
verb + adverb
