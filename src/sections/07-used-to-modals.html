7. Used to и модальные глаголы

Три конструкции used to и базовая формула модальных глаголов.

Used to: раньше делал

used to + V1

Привычное действие или состояние в прошлом, которого сейчас уже нет.

I used to play tennis.
She used to live here.
После used to: только начальная форма глагола — V1.

Be / get used to: привыкнуть

be/get used to + noun / V-ing

be used to — быть привыкшим; get used to — привыкать.

I'm used to working late.
He is getting used to it.
Не путай: used to work, но be used to working.

Вопросы и отрицания

отрицание I didn't use to smoke.
вопрос Did you use to smoke?
не привык I'm not used to it.
привыкаешь? Are you getting used to it?
После did: use to, не used to.

Модальные глаголы

can / could возможность, просьба
should совет
must / have to обязанность
would условие, вежливая форма
modal + V1
She can swim. · You should wait.
Без to и -s: can go, не can to go и не can goes.
